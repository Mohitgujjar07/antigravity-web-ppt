Chapter 1

What Is Google Antigravity?

Google Antigravity is a new agentic development platform released in November 2025. It evolves the traditional IDE into an agent-first experience, where autonomous AI agents can plan, code, test, and even browse the web to help you build — with minimal human intervention.

Unlike standard coding assistants that just autocomplete lines of code, Antigravity provides a "Mission Control" for managing autonomous agents that handle complex, multi-step engineering tasks on your behalf.

🧠

Agent-First

AI is not just a tool — it's an autonomous actor that plans, executes, validates, and iterates on tasks independently.

⚡

Parallel Execution

Dispatch multiple agents simultaneously on different tasks — no more waiting in a linear chat flow.

🌐

Browser Integration

Agents can open URLs, read web content, and interact with pages to test and verify applications visually.

📦

Artifacts

Tangible deliverables — plans, screenshots, walkthroughs — that let you verify agent work at a glance.

Chapter 1

The Problem It Solves

Before — Traditional AI Assistants

  • Chatbot in a sidebar — linear, synchronous conversations
  • Developers must wait for AI to finish before the next question
  • AI suggests code snippets but cannot plan or execute multi-step tasks
  • No ability to browse, test, or verify output autonomously
  • Context is limited to the current chat window

After — Antigravity's Agent-First Model

  • Dedicated "Manager Surface" for orchestrating multiple agents
  • Agents work asynchronously — dispatch 5 tasks at once
  • Agents plan, code, test, fix errors, and iterate autonomously
  • Browser tool lets agents test UI and verify behavior visually
  • Artifacts provide reviewable deliverables, not just raw logs

Key shift: The developer moves from "someone filling out code snippets" to an "architect" or "manager", orchestrating a workforce of digital agents.

Chapter 2

Core Architecture

Antigravity is built on the open-source VS Code foundation but fundamentally changes the UX by placing agent management above text editing. The interface is split into two distinct windows:

📝

The Editor View

A state-of-the-art, AI-powered IDE with tab completions and inline commands — for when you need to be hands-on with code. This is the familiar VS Code experience enhanced with AI.

🎛️

The Agent Manager

The "Mission Control" — a dedicated interface where you spawn, orchestrate, and observe multiple agents working asynchronously across different workspaces.

🌐

Browser Tool

Agents can open URLs, read page content, interact with elements, and execute JavaScript — enabling real-time UI testing and web scraping.

📄

Artifacts

Tangible deliverables like task lists, implementation plans, screenshots, and browser recordings that agents generate for your review. Think of them as "comment-able docs."

Chapter 2

Agent Manager — Deep Dive

The Agent Manager is where the paradigm shift happens. It acts as a task control center for managing autonomous agents that run in parallel across different workspaces or tasks.

What You Can Do

  • Generate, monitor, and interact with multiple agents
  • Define high-level goals: "Refactor auth module," "Generate test suite," "Update dependencies"
  • Each request spawns a dedicated agent instance
  • View agent status, generated artifacts, and pending approval requests
  • Leave feedback directly on artifacts — like commenting on a Google Doc

Why It Matters

  • No more linear waiting: Dispatch 5 agents for 5 different bugs simultaneously
  • Trust through transparency: Artifacts show exactly what the agent is doing
  • Async by design: Focus on your primary work while agents handle background tasks
  • Model flexibility: Choose between Gemini 3 Pro, Claude Sonnet 4.5, or GPT-OSS

Chapter 3

Agent Modes at Setup

During setup, Antigravity asks how autonomous you want your agents to be. Four preset options are available:

Safe Mode

Enhanced security controls. Limits agent access to external resources and sensitive operations. Maximum safety, minimum autonomy.

Feedback-Oriented (Recommended)

Agents frequently seek your feedback. Good balance of autonomy and control. The recommended starting point for new users.

Agent-Driven

Agents never request review. Full autonomy — fastest execution but least oversight. Use only when you fully trust the task scope.

Custom Configuration

Fine-tune every policy individually: terminal execution, review requirements, and JavaScript execution. For advanced users.

You can change these settings anytime via Antigravity User Settings (Ctrl+, / Cmd+,).

Chapter 3

Security Policies Explained

Three independent policy dimensions control agent behavior:

Terminal Execution Policy

Always Continue — Auto-execute all commands (except deny-list).
Request Review — Ask approval before every terminal command.

Review Policy

Always Continue — Agent never asks for review.
Agent Decides — Agent chooses when to seek approval.
Request Review — Always ask before proceeding.

JavaScript Execution Policy

Always Continue — Run JS freely in browser (highest risk).
Request Review — Ask permission before JS execution.
Disabled — Never run JavaScript in the browser.

Allow / Deny Lists

Configure specific terminal commands that are always allowed or always blocked, regardless of the overall policy. Essential for security-conscious teams.

Chapter 4

Key Concepts

💬

Prompts & Tasks

You describe what you want in natural language. The agent interprets intent, breaks it into steps, and executes. Example: "Build a cyberpunk to-do list with neon colors and glitch effects."

📎

Context with @

Use @ to add files, folders, or other context to your prompts — similar to Cursor or Gemini CLI. This helps agents understand your project structure.

📊

Model Selection

Choose from available models via the dropdown: Gemini 3 Pro (default "Fast" mode), Claude Sonnet 4.5, GPT-OSS, and more.

📁

Workspaces

Just like VS Code — open a local folder as your workspace. Agents operate within the context of the selected workspace.

📋

Artifacts

Agents produce deliverables — task plans, implementation diffs, screenshots, walkthrough docs. You can comment on them directly for targeted feedback.

🔧

CLI Companion

Install the agy command-line tool during setup to open Antigravity from the terminal with the command agy .

Chapter 4

Understanding Artifacts

Artifacts are how agents communicate their work to you. Instead of scrolling through raw tool calls and logs, you get structured, reviewable deliverables:

Types of Artifacts

  • Task Plans — Step-by-step breakdown of what the agent will do
  • Implementation Plans — Technical approach and architecture decisions
  • Diffs — Code changes the agent has made
  • Screenshots — Visual proof of UI changes
  • Walkthroughs — Narrative docs explaining what was done and why
  • Browser Recordings — Captures of the agent testing in the browser

How to Use Them

  • Review at a glance — No need to read every line of code
  • Comment directly — Like commenting on a Google Doc; leave targeted feedback on specific parts
  • Agent incorporates feedback — Without stopping its execution flow
  • Builds trust — See exactly what the agent did and why

Unlike chat-based tools, walkthroughs are not written to your project workspace — they don't clutter up your project with point-in-time documents.

Chapter 6

Skills — A Preview

Skills address "Context Saturation" — the problem of loading hundreds of tools and entire codebases into the model's memory, causing latency, cost, and confusion.

The Problem

  • Agents loaded with hundreds of tools from various MCP servers
  • 40–50K tokens consumed before the agent even starts your task
  • Context rot: the model gets confused by irrelevant information

The Solution: Progressive Disclosure

  • Skills are modular, discoverable packages of specialized knowledge
  • Model sees only a lightweight "menu" (metadata) at session start
  • Heavy instructions loaded only when intent matches
  • Turns the generalist Gemini model into a specialist on demand

Note: Skills are covered in depth in Part 2 (Advanced). This is just a preview of why they exist and what problem they solve.

Chapter 6

Tips for Getting Started

Best Practices

  1. Start with "Feedback-Oriented" mode — gives you visibility into what agents are doing while maintaining good autonomy
  2. Be specific in prompts — describe the vibe, tech stack, and constraints clearly
  3. Use @ to add context — reference files, folders, and code to guide the agent
  4. Review Artifacts, not code — trust the artifact system for verification
  5. Start small — try a simple task first to understand the workflow before delegating complex projects

Things to Know

  • Free preview available with personal Gmail — not Workspace accounts yet
  • Generous rate limits on Gemini 3 Pro during the preview period
  • Quota limits may change — Google is still tuning the economics
  • MCP server support available but still expanding
  • Browser tabs can accumulate — no auto-close feature yet
  • Works best with Chrome for browser integration features

Summary

Key Takeaways

  1. Antigravity is agent-first, not chat-first. It treats AI as autonomous actors, not passive assistants.
  2. The developer becomes an architect. You define goals; agents handle implementation, testing, and iteration.
  3. Parallel agents = massive throughput. Dispatch multiple tasks simultaneously instead of waiting in a linear chat.
  4. Artifacts build trust. Structured deliverables replace raw logs for transparent, reviewable agent work.
  5. Browser integration is a game-changer. Agents can visually test and verify your applications in real-time.
  6. Security is configurable. Three policy dimensions let you control exactly how much autonomy agents have.
  7. Free and accessible. Available now in public preview with a personal Gmail account on Mac, Windows, and Linux.
